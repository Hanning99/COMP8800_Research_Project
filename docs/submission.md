# Supervisor and Wattle handover

Use the GitHub repository as the single entry point:
<https://github.com/Hanning99/COMP8800_Research_Project>.
The README links the separate checkpoint dataset and records how to obtain and verify it.

The submission arrangement follows the supplied ANU Individual Computing Projects marking-guide text: deliver the artefact directly to the supervisor and submit an access link on Wattle. Wattle submission and messages to the supervisor are performed by the author; this package does not send either automatically.

After successful private upload, `PUBLISH_RECEIPT.json` contains:

- the full GitHub commit SHA and `/tree/<commit>` link;
- the immutable Hugging Face dataset revision and its fixed link;
- the GitHub link to submit to Wattle.

Grant the supervisor access to both private repositories before handing over those links. Verify access using the supervisor's account; public URL syntax alone does not prove private access. Keep the repositories private until the author chooses to make them public.

The handover identifies the report by its SHA-256, explains the installation environment, provides checkpoint evaluation and training-continuation commands separately, and includes actual verification evidence. It does not claim that a local package is already online or that all source pretraining was repeated.
