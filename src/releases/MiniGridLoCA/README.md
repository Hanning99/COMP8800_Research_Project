# MiniGridLoCA: neural-reference effectiveness experiment

This standalone package reproduces the **bottom row (neural reference)** of the supplied MiniGridLoCA full-continuation figure: AWAC, SAC, and expected-SARSA QAC, eight methods, all 20 paired seeds per backbone (480 runs). It preserves the `mapped_best` selection and the latest CQL/IQL tuning results dated 2026-10-02. Exact-reference runs and alternative PDR coefficient sweeps are not included.

## Scope and checkpoints

- `RUNS.json` is the authoritative run/configuration/path index. All executable paths are package-relative; historical absolute paths in provenance are not runtime dependencies.
- `inputs/loca_neural/branches/confirmatory/*/seed_*/BRANCH.pt`: the 60 frozen neural-critic/actor branches, including target networks and available optimizer states. **No neural-critic pretraining is required.** The original directory word `confirmatory` is historical: the later selection and reporting here use the same development cohort.
- `starts/*/seed_*/COMMON_INITIAL.pt`: complete common initialization, RNG states, and archived replay schedule information for each backbone/seed.
- `runs/*/seed_*/METHOD/`: all files in each selected source run, including initial/final checkpoints where originally saved, CQL/IQL early checkpoints, raw learning curves, diagnostics, and recorded policies/snapshots. PDR shares its complete initial checkpoint through `RUNS.json` rather than a redundant per-run copy.
- `src/` and `vendor/`: original training, environment, model, evaluator, replay and PDR numerical code. Only environment-specific Python search paths and optional device selection were adapted; see `provenance/PORTABILITY.patch`. `provenance/code/` preserves originals. Pretraining is outside this reproduction workflow; no training of the supplied anchors is invoked.
- `provenance/analysis/`: source selection tables and configuration explanations (including historical exact-reference metadata for provenance, **not exact-reference experiment checkpoints**).
- `results/`: CSV-derived neural-only early/full plots and recomputed statistics. Plots have three panels, without the unused exact-reference row. No smoothing or seed exclusion is applied.
- `validation/`: completed validation reports, with their precise scope. `SHA256SUMS` seals the distributed package.

## Environment and execution

Validated environment: Python 3.10, PyTorch 2.5.1 CUDA 12.1, NVIDIA RTX 3090, single-threaded BLAS, TF32 off, deterministic PyTorch operations. Install the CUDA-enabled PyTorch build appropriate to your system, then `pip install -r requirements.txt`. A C++17 compiler is needed for the PS baseline. The package uses a self-contained MiniGridLoCA graph; no external experiment checkout or dataset download is required. Checkpoints are Python/PyTorch pickle files and must only be loaded from a trusted source.

From this directory:

```bash
# Check distributed files before regenerating build outputs.
sha256sum -c SHA256SUMS
python scripts/build.py

# Rebuild all 480-run statistics and neural-only plots, without training.
python scripts/aggregate.py --out reproduced_results

# Verify copied evidence, load every checkpoint, check replay schedules,
# evaluate saved policies and reconstruct/evaluate all 480 final actors on CPU.
python scripts/verify.py --out local_validation/integrity.json

# Replay PDR from a supplied neural branch through all 4,096 actor updates.
CUDA_VISIBLE_DEVICES=0 python scripts/reproduce.py --backbone AWAC --method PDR --out reruns/awac_pdr
CUDA_VISIBLE_DEVICES=0 python scripts/reproduce.py --backbone SAC --method PDR --out reruns/sac_pdr
CUDA_VISIBLE_DEVICES=0 python scripts/reproduce.py --backbone QAC --method PDR --out reruns/qac_pdr

# Examples: short baseline replay and direct final-checkpoint evaluation.
CUDA_VISIBLE_DEVICES=0 python scripts/reproduce.py --backbone SAC --method CQL --updates 128 --out reruns/sac_cql_128
CUDA_VISIBLE_DEVICES=0 python scripts/reproduce.py --backbone AWAC --method PER --mode final --out reruns/awac_per_final

# Resume a checkpoint generated by this portable runner.
CUDA_VISIBLE_DEVICES=0 python scripts/reproduce.py --backbone SAC --method CQL --updates 256 --resume reruns/sac_cql_128/CHECKPOINT.pt --out reruns/sac_cql_256
```

Supported methods: `TD`, `PER`, `DISCOR`, `EXTRA_TD` (8x TD), `IQL`, `CQL`, `PS`, `PDR`. `--seed` selects any of the archived 20 seeds; omitted means the first seed in `RUNS.json`. All output directories must be new. Use exactly one visible GPU per training process. `--mode early` evaluates the archived CQL/IQL checkpoint at update 1,024. Different hardware/library versions can produce floating-point deviations; the runner reports differences rather than silently rewriting reference results.

## Task, evaluation and training protocol

The 8x8 task has 256 position/orientation states and three actions (turn left, turn right, move forward). Task A rewards T1/T2 with 4/2; Task B rewards them with 1/2. The transition graph and the T1-region restriction are unchanged. The neural input is the Markov state ID (embedding 128; hidden layers 256 and 512 with LeakyReLU), not RGB. The release is a **matched reward-switch continuation with fixed replay and complete transition support**, not a from-scratch online-exploration comparison.

The plotted metric is `task_b_exact_discounted_return`: the exact expected Task-B return over a 100-step evaluation horizon, discount 0.99, averaged over nonterminal starting states. The evaluator's exact integration is not an exact critic supplied to neural PDR. Progress is measured in actor updates, ending at 4,096. `Early` is trapezoidal AUC over 0--1,024 divided by 1,024; `Full` uses 0--4,096; `Final` is the value at update 4,096. Bands are pointwise 95% percentile seed-bootstrap intervals (10,000 resamples, RNG seed 20260925). Paired comparisons use differences within the same seed. All 20 development seeds are retained; selection and reporting share that cohort, so intervals are conditional on selected configurations, not independent held-out estimates.

Common batch size is 128; actor/critic Adam learning rates are 0.001, target Polyak tau 0.02, unless overridden by the archived baseline recipe. AWAC temperature is 0.25, weight cap 20. SAC uses twin critics and soft coefficient 0.001; QAC uses the expected-policy-gradient objective. CQL and IQL use their own native objectives, warm-started from each matched backbone branch, rather than being relabeled AWAC/SAC/QAC updates. Baseline hyperparameters, actor gains and update counts are preserved exactly in `RUNS.json`.

PDR freezes the neural Task-A reference, keeps ordinary critic learning, and solves the policy differential on the full graph with the reward-change term `r_B - r_A`. The plotted AWAC arm is `REF1_DELTA8` (alpha=1, beta=8); SAC/QAC use `REF4_DELTA8` (alpha=4, beta=8). In the `A_full + eta Delta_A` notation, these are eta=7 for AWAC and eta=1 with **outer actor-loss scale 4** for SAC/QAC. SAC's original loss remains `E_pi[0.001 log pi - (4 Q_ref + 8 Delta_Q)]`. No actor-loss multiplier is silently removed or absorbed into Adam. The package reuses the recorded arithmetic, not a newly rewritten equivalent expression.

PDR coefficients and the non-CQL/IQL baseline configurations were selected on the development cohort; CQL/IQL were selected by highest final Task-B return on the same 20-seed cohort. The original main figure retains their intermediate collapses as well as their later recovery. All observations are preserved.

## Verification boundaries

Figure regeneration must match the original plotted means and bootstrap intervals to 1e-12. `scripts/verify.py` checks all selected checkpoint files and all final actor returns, while `scripts/reproduce.py` compares actual training continuations with archived curve points and saved policies when available. See `DELIVERY_VERIFICATION.json` and `validation/` for tests actually completed; do not interpret a figure rebuild as a full rerun of every training trajectory. Original wall-clock measurements can reflect shared GPUs and do not establish equal-time comparisons.

The original official-study reference and upstream commit are recorded in `inputs/loca_exact/PROTOCOL_LOCK.json`; the directory name holds the shared task/configuration definition only, not exact-reference branches. Source histories and provenance hashes are retained without requiring the original absolute paths to exist.
